# Pac-Man Project

## How To Run
- Clone repository via HTTPS
```
git clone https://github.com/loganduffy/pacman-game.git
```
- Open the repository via Intellij IDEA
- Run PacmanApplication.java
- Click Start Game

## Game Objective
- Collect all the dots on the level to win
- Collect P-Pellets to make ghosts temporarily scared
- Don't lose all your lives to the ghosts
- Try to beat your highscore
